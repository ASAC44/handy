# Project Instructions

## UI Design

- Use a minimal, flat visual style with clear hierarchy, deliberate spacing, and strong typography.
- Keep the color palette restrained and use accent colors only for meaningful states or actions.
- Avoid gradients, glassmorphism, glows, decorative blobs, excessive shadows, and ornamental animations.
- Prefer simple shapes, solid fills, subtle full borders, and consistent corner radii.
- Keep controls compact, functional, and visually quiet; avoid inflated cards and marketing-style decoration.
- Preserve the existing visual language and components unless a redesign explicitly requires changing them.
- Never use a left border by itself as a visual design treatment. Use a full border, background, spacing, or another intentional treatment instead.

## Image Generation

- Before generating an original image asset, read and apply `docs/image-generation-style.md`.
- The reference defines an image-only exception to the general glassmorphism restriction above; it does not authorize glassmorphism elsewhere in the interface.
- Task-specific user direction takes precedence when it conflicts with the reference.
